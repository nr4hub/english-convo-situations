1

The situation

You have to record (or present live) a video demonstration of a cybersecurity home-lab project. Example topic: “Build a Free SIEM Lab with Wazuh.” You talk while your screen shows the lab — so your words must guide the viewer through every click and command.

Tip: A video is different from a classroom talk. Your audience can't interrupt you, so say what you are doing before you do it and say what the result means after you do it.
Safety note: Always say that everything happens in an isolated virtual lab, for educational purposes only. Never demonstrate attacks on real systems.
2

Plan the video

Good demo videos follow the same six-part shape. Use this timeline as your script skeleton (about 12 minutes; shorten each part for a 5-minute class demo).

TimePartWhat you do
0:00 – 0:30HookWhy this project matters for getting a SOC job
0:30 – 1:30Overview & requirementsTools, laptop specs, what the viewer will learn
1:30 – 3:00Architecture diagramExplain the machines and the network
3:00 – 10:00Live demoInstall, configure, and test — step by step
10:00 – 11:30ResultsShow the logs / dashboard and explain them
11:30 – 12:00Recap & call to actionSummarize, thank, invite comments
Before you press record
  • Test your microphone and close other apps
  • Increase the font size in the terminal and browser
  • Prepare the lab: VMs created, snapshots taken
  • Write short notes for each step - do not read word for word
  • Do one full practice run and time yourself
3

Step 1 — Hook & overview

Start with the problem, then promise the result. Tell the viewer exactly what they will build.

Opening
  • Greet and introduce yourself
  • State the problem in one sentence
  • Promise the result (what they will have at the end)
  • List the requirements
Hooking the viewer
You
Hello everyone, and welcome to another home lab. My name is Nero, and in today's video I'll be showing you how to build a free SIEM lab using Wazuh.සියලුදෙනාට ආයුබෝවන්, තවත් home lab එකකට සාදරයෙන් පිළිගන්නවා. මගේ නම නෙරෝ, අද video එකේදී Wazuh භාවිතයෙන් නොමිලේ SIEM lab එකක් හදන හැටි පෙන්නනවා.
You
Most recruiters want hands-on experience, so this project is a great way to practise real SOC analyst skills.බොහෝ recruiters ට ඕන hands-on experience, ඒ නිසා මේ project එක SOC analyst කුසලතා පුහුණු වෙන්න හොඳ ක්‍රමයක්.
You
By the end of this video, you'll have a manager collecting logs from a Windows agent, and you'll see file changes appear on the dashboard.video එක අවසන් වෙද්දී, Windows agent එකකින් logs එකතු කරන manager කෙනෙක් ඔබට ඇති, ෆයිල් වෙනස්කම් dashboard එකේ පෙනෙනවා.
You
For this lab, you'll need a laptop with at least 8 gigabytes of RAM, VirtualBox, and an Ubuntu virtual machine. Everything is completely free.මේ lab එකට අවශ්‍ය අවම වශයෙන් RAM 8GB ක laptop එකක්, VirtualBox, සහ Ubuntu virtual machine එකක්. සියල්ලම නොමිලේ.
4

Step 2 — Explain the lab architecture

Show a simple diagram first. The viewer should understand the big picture before they see any commands.

Architecture slide
  • Draw or show a diagram with the machines
  • Name each machine and its role
  • Explain how they connect (network type)
  • Point with your cursor while you talk
Explaining the diagram
You
Let's start with the big picture. As you can see in this diagram, we have two machines.මුලින්ම මුළු චිත්‍රය බලමු. මේ diagram එකේ පේන විදිහට, අපිට machines දෙකක් තියෙනවා.
You
The Ubuntu machine is our Wazuh manager, and the Windows machine is our agent.Ubuntu machine එක අපේ Wazuh manager, Windows machine එක අපේ agent.
You
The agent collects events and sends them to the manager, where we can view them on a dashboard.agent එක events එකතු කරලා manager ට යවනවා, එතකොට dashboard එකේ බලන්න පුළුවන්.
You
Both machines are on the same network using a bridged adapter, so they can communicate in both directions.machines දෙකම bridged adapter එකකින් එකම network එකේ, ඒ නිසා දෙපැත්තටම communicate කරන්න පුළුවන්.
5

Step 3 — The live demo

This is the heart of the video. Use the pattern: say what you will do → do it → explain the result. Use short, clear sentences and the present continuous for actions.

Demo narration pattern
  • Announce: “Now I'm going to…”
  • Act slowly — let the viewer see each click
  • Explain: “This tells us that…”
  • Mention mistakes and fixes honestly
  • Use signposts: first, next, after that, finally
Narrating the demo
You
First, let's check the IP address of our Ubuntu machine. I'm typing the command ‘ip a’, and as you can see, the address is 192.168.0.217.මුලින්ම Ubuntu machine එකේ IP address එක බලමු. මම ‘ip a’ command එක type කරනවා, ඔබට පේන විදිහට address එක 192.168.0.217.
You
Next, I'm going to run the installation script. This step takes about ten minutes, so I'll skip ahead.ඊළඟට, installation script එක run කරනවා. මේ step එකට විනාඩි දහයක් විතර යනවා, ඒ නිසා මම ඉස්සරහට skip කරනවා.
You
The installer has finished. Notice that it shows a username and a password — let's copy the password, because we'll need it to log in.installer එක ඉවරයි. username එකයි password එකයි පෙන්නනවා බලන්න — login වෙන්න ඕන නිසා password එක copy කරගමු.
You
Now I'm opening the dashboard in the browser. Don't worry about the security warning — it appears because we're using a self-signed certificate in our lab.දැන් browser එකේ dashboard එක open කරනවා. security warning එක ගැන කරදර වෙන්න එපා — lab එකේ self-signed certificate එකක් භාවිත කරන නිසා එය එන්නේ.
You
Finally, I'm adding the Windows agent. Once I enter the manager's IP and the authentication key, the agent should connect within a few seconds.අවසානයේ, Windows agent එක add කරනවා. manager ගේ IP එකයි authentication key එකයි ඇතුළත් කළාම, agent එක තත්පර කිහිපයකින් connect වෙන්න ඕන.
6

Step 4 — Show results & close

Prove that the project works, explain what the viewer is looking at, then give a short recap and a call to action.

Results & closing
  • Trigger a test event (create / delete a file)
  • Show the matching log on the dashboard
  • Explain what a SOC analyst would learn from it
  • Recap in two sentences, thank the viewer, invite comments
Wrapping up the video
You
To test it, I'm creating a new text file in the monitored folder. Let's see what happens on the dashboard.test කරන්න, monitor කරන folder එකේ අලුත් text file එකක් හදනවා. dashboard එකේ මොකද වෙන්නේ කියලා බලමු.
You
There it is! The alert shows the file path, the time, and the event type — ‘added’. This is called file integrity monitoring.මෙන්න! alert එකෙන් file path එක, වේලාව, සහ event type එක — ‘added’ පෙන්නනවා. මේකට කියන්නේ file integrity monitoring කියලා.
You
In a real SOC, this helps analysts detect suspicious changes on an endpoint, such as ransomware modifying files.සැබෑ SOC එකක, endpoint එකක ransomware ෆයිල් වෙනස් කිරීම වැනි සැක සහිත වෙනස්කම් හඳුනාගන්න මෙය විශ්ලේෂකයන්ට උදව් වෙනවා.
You
To recap, we installed a Wazuh manager, connected a Windows agent, and detected a file change in real time.සාරාංශයක් විදිහට, අපි Wazuh manager එකක් install කළා, Windows agent එකක් connect කළා, සහ ෆයිල් වෙනසක් real time එකේ හඳුනාගත්තා.
You
Thank you for watching. If you enjoyed this lab, please like the video, subscribe, and leave a comment with your questions.බලපු ඔබට ස්තූතියි. මේ lab එක ප්‍රිය වුණා නම්, video එකට like කරලා, subscribe කරලා, ප්‍රශ්න comment එකක් විදිහට දාන්න.

8

Grammar focus

Three patterns you will use constantly while narrating a screen demo.

Present continuous — actions happening nowCore tense

Use ‘am/is/are + -ing’ for what you are doing on screen at this moment.

  • I'm opening the dashboard now.මම දැන් dashboard එක open කරනවා.
  • The installer is running.installer එක run වෙමින් පවතිනවා.
Future with ‘going to’ / ‘will’ — announcing the next stepSignposting

Say what you are about to do so the viewer is ready.

  • Now I'm going to install the agent.දැන් මම agent එක install කරන්න යනවා.
  • Next, we'll check the logs.ඊළඟට, logs බලමු.
Imperative — giving instructions to the viewerInstructions

Use the base verb to tell viewers what to do. Add ‘please’ or ‘make sure’ to sound friendly.

  • Copy the password.password එක copy කරන්න.
  • Make sure both machines are on the same network.machines දෙකම එකම network එකේ බව තහවුරු කරගන්න.
Passive voice — describing technical processesTechnical writing

Use the passive when the process matters more than who does it.

  • The logs are sent to the manager.logs manager ට යවනු ලබනවා.
  • The agent is installed on Windows.agent එක Windows මත install කර ඇත.
9

Common mistakes

Fixes that instantly make your demo sound more fluent.

Common mistakeCorrect versionWhy
I am click the button now.I'm clicking the button now.Use present continuous: am/is/are + verb-ing.
Now we go to next step.Now let's move on to the next step.Use a signpost phrase and the article ‘the’.
This lab is use for learning.This lab is used for learning.Passive voice needs ‘is + past participle’.
You can see here the logs.As you can see, the logs are here.Use a natural opening phrase; keep normal word order.
I will showing you how to install.I'll show you how to install it.After ‘will’, use the base verb.
Don't scared about the error.Don't be scared of the error. / Don't worry about it.Use ‘be’ before the adjective, or ‘worry about’.
